# Results Output Contract

Paper results are not manually entered into this file. The authoritative
results surface is generated by `scripts/build_paper_artifacts.py` from
completed canonical raw-run directories.

## Main result dimensions

The generated summary/table pipeline is prepared to report, when present in raw
runs:

| Dimension | Examples |
|---|---|
| Final performance | final average, post-training return, final success |
| Retention | forgetting, backward transfer |
| Transfer | forward transfer / benchmark-specific transfer |
| Lifetime learning | lifetime AUC |
| Adaptation | T80, T90, post-change AUC |
| Recurrence | revisit/reacquisition metrics |
| Plasticity | plasticity retention, sigma/effective-LR diagnostics |
| Detection | surprise delay, precision/recall/F1, AUROC |
| Compute | wall-clock, steps, parameter/memory overhead where recorded |
| Protocol | task-ID/boundary/context access assumptions |

For each scalar metric, the aggregate table records mean, sample standard
deviation, percentile bootstrap interval, seed count, raw values, contributing
run IDs, and seeds. Task-within-seed metrics are aggregated separately with
hierarchical bootstrap. Matched methods also receive paired-seed difference
tables.

## Generated artifacts

The current Phase-15 builder emits:

- `aggregate_statistics.{csv,md,tex}`;
- `hierarchical_task_statistics.{csv,md,tex}`;
- `paired_differences.{csv,md,tex}`;
- `results_summary.{csv,md,tex}`;
- `information_access.{csv,md,tex}`;
- `run_index.{csv,md,tex}`;
- confidence-banded learning/adaptation/timeline figures when raw columns exist;
- continual return/success matrices when raw matrix rows exist;
- `paper_manifest.json` with every source hash and skipped-figure reason.

No cell is considered a result until its source run is completed and traceable
through this manifest. Failed/partial seeds make strict aggregation fail rather
than leaving a blank or silently disappearing.
