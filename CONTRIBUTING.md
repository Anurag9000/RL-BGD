# Contributing

RL-BGD is a research repository. Changes should preserve scientific traceability.

1. Keep equations, code, tests, configs, and documentation synchronized.
2. Never add fabricated result files or transcribed paper numbers as reproduced results.
3. Add tests when changing numerical or information-access semantics.
4. Keep optional benchmark dependencies out of the base import path.
5. Record deviations from cited papers instead of implying exact reproduction.
6. Use deterministic seeds in tests; do not promise cross-device bitwise identity where PyTorch does not provide it.
